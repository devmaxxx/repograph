# 0.5.0 Gap-Closing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship in 0.5.0 whichever of four levers passes a rule written before its numbers are read: a scale-free admission for the generated-questions list and, on the same rule, one seat for the code list (G12, G8, G13); the BM25 indexes held resident instead of rebuilt per question (the perf results' 49 ms); floors for the default embedder; and an enrichment prompt that knows a decision from a behaviour (G14). Record every measurement, passed or failed, in the docs and the history.

**Architecture:** repograph is a Rust CLI (`src/`) over a `.repograph/` store (graph, BM25 built at query time, dense vectors on disk, generated questions). Retrieval fuses ranked lists round-robin into five seeds (`src/query.rs::ask`, `src/index/fuse.rs::interleave`); the questions list joins the plain fusion only when it clears an admission (`QUESTIONS_GATE = 0.85`, a ratio of two indices' best scores). `ask::Context` holds everything but the BM25 indexes across answers. Every retrieval lever is first replayed offline over `dump` files, then confirmed live on the read-only fixture and on store copies, judged by the rule in the spec, and recorded in the SDD ledger, the results doc and `bench/history/runs.jsonl`.

**Tech Stack:** Rust 2021 (`cargo test --release`, `cargo clippy --release --all-targets -- -D warnings`), Python 3 stdlib only (`bench/heldout.py`, `bench/history/track.py`, the new `bench/admission.py`), bash 3.2, the `claude` CLI as the question generator (Task 6 only).

**Spec:** `docs/superpowers/specs/2026-09-05-0.5.0-gaps-design.md` — the four levers, their rules, what is out and why. The gaps themselves are in `docs/bench/next-version-gaps.md` (G8, G12, G13, G14) and the perf leftover in `docs/bench/2026-09-06-perf-results.md` ("The lexical arm misses the 30 ms target"). The spec outranks this plan where they disagree.

- [ ] **Step 3: Implement**

In `impl LexicalIndex`, replace the inline idf in `search` with a shared function and add the two methods:

```rust
    /// BM25's idf for a term seen in `df` of this index's `n` documents.
    fn idf(n: f32, df: usize) -> f32 { ((n - df as f32 + 0.5) / (df as f32 + 0.5) + 1.0).ln() }

    pub fn is_empty(&self) -> bool { self.ids.is_empty() }

    /// What the query could reach in this index: the score of a document of average length that
    /// holds each of the query's terms exactly once, which BM25 makes the plain sum of their idf
    /// — at tf = 1 and the mean length the term weight `(K1 + 1) / (1 + K1)` is one. A term this
    /// index never saw adds nothing here, as it adds nothing to any document's score. A list's
    /// best over this figure says how much of the query the best document answered, and unlike
    /// the best score itself it compares across indices: each index normalises length against
    /// its own mean and weights a term by its own vocabulary, so two indices' raw scores are in
    /// two units and their ratio moves when either population does (gaps G8 and G12).
    pub fn attainable(&self, query: &str) -> f32 {
        let n = self.ids.len() as f32;
        let mut seen = std::collections::HashSet::new();
        tokenize(query).into_iter().filter(|t| seen.insert(t.clone()))
            .filter_map(|t| self.postings.get(&t).map(|list| Self::idf(n, list.len())))
            .sum()
    }
```

and in `search`: `let idf = Self::idf(n, list.len());` in place of the three-line expression.

`bench/admission.py`:

```python
#!/usr/bin/env python3
"""Replays the plain `ask` fusion over `dump` files under a named admission rule, so a candidate
rule is read on the held-out set, the recorded suite and the developer suite from the lists the
binary already recorded — no rebuild, no re-run, no tokens — and the binary is changed once, for
the rule that passed.

The replay is checked before it is trusted: `check` re-derives every dump's own recorded answer
under a rule and refuses to go on unless it matches on every query. Under the shipped rule
(`ratio 0.85`) that is the proof the replay is `query::ask`; under a new rule, on dumps from a
binary carrying it, it is the proof the binary is the replay.

Forms, each a statistic of one list alone, so two lists compare in one unit:

    ratio     best(Q) / best(P)                              the shipped gate — a constant of one store (G8, G12)
    coverage  (best/attainable)(Q) / (best/attainable)(P)    how much of the query each list's best answered
    peak      (best/fifth)(Q) / (best/fifth)(P)              how far each best stands above its own list; five seats
    z         z(Q) / z(P)                                    the best as a z-score over the list, 20 deep

Order of operations, as `heldout.py`'s header says and not optionally: a form's constant is the
crossover on the held-out dumps (`crossover`), the recorded and developer suites are read after
it is fixed (`score`), and the first form in the pre-registered order that passes the rule is
the one the binary gets. Nothing here is adjusted after a suite has been read.
"""
import argparse
import json
import math
import statistics
import struct
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
from heldout import anchors, mcnemar  # noqa: E402

# `query::ask` expands along these kinds and no other.
EXPAND = {"References", "Implements", "Declares", "Links", "Legacy"}
# The plain path searches every list this deep; a dump records 300.
PLAIN_DEPTH = 20
SEATS = 5
FORMS = ("ratio", "coverage", "peak", "z")


def f32(x):
    """The value as the binary holds it: `lexical_lists` compares f32 products."""
    return struct.unpack("f", struct.pack("f", x))[0]


def load(path):
    return json.loads(Path(path).read_text())


def store_of(path):
    """Neighbours along the expansion kinds, each node's file, and whether the store has
    generated questions at all — a store without them fuses the passage list alone."""
    g = load(Path(path) / "graph.json")
    nb = {}
    for e in g["edges"]:
        if e["kind"] in EXPAND:
            nb.setdefault(e["source"], []).append(e["target"])
            nb.setdefault(e["target"], []).append(e["source"])
    files = {i: n["file"] for i, n in g["nodes"].items()}
    q = Path(path) / "questions.json"
    has_questions = bool(load(q)["entries"]) if q.exists() else False
    return nb, files, has_questions


def ids(scored):
    return [i for i, _ in scored]


def interleave(lists):
    """`fuse::interleave`: rank r of every list before rank r + 1 of any, first position kept."""
    out, seen = [], set()
    for rank in range(max((len(l) for l in lists), default=0)):
        for l in lists:
            if rank < len(l) and l[rank] not in seen:
                seen.add(l[rank])
                out.append((l[rank], 1.0 / (rank + 1)))
    return out


def stat(form, scored, attainable):
    scored = scored[:PLAIN_DEPTH]
    if not scored:
        return 0.0
    best = scored[0][1]
    if form == "ratio":
        return best
    if form == "coverage":
        return best / attainable if attainable > 0 else 0.0
    if form == "peak":
        if len(scored) < SEATS or scored[SEATS - 1][1] <= 0:
            return math.inf
        return best / scored[SEATS - 1][1]
    if form == "z":
        s = [x for _, x in scored]
        if len(s) < 2:
            return math.inf
        sd = statistics.pstdev(s)
        return (best - statistics.fmean(s)) / sd if sd > 0 else math.inf
    raise SystemExit(f"unknown form {form}")


def sratio(form, own, theirs):
    """The list's statistic over the passage list's, with the ends spelled out: a passage list
    with nothing is never a bar (inf), two lists both peaks of their own compare level (1)."""
    if own == math.inf and theirs == math.inf:
        return 1.0
    if own == math.inf:
        return math.inf
    if theirs == math.inf:
        return 0.0
    return math.inf if theirs <= 0 else own / theirs


def admitted(form, c, lst, passages, a_list, a_passages):
    """Whether `lst` is seated beside `passages` under `form` at constant `c`."""
    lst, passages = lst[:PLAIN_DEPTH], passages[:PLAIN_DEPTH]
    if not lst or lst[0][1] <= 0:
        return False
    if form == "ratio":
        theirs = passages[0][1] if passages else 0.0
        return f32(lst[0][1]) >= f32(f32(c) * f32(theirs))
    return sratio(form, stat(form, lst, a_list), stat(form, passages, a_passages)) >= c


def lexical_lists(rec, form, c, code_seat, has_questions):
    """`query::lexical_lists` on the plain path: [questions?] [passages] [code top-1?]."""
    p, q, code = rec["bm25_passages"], rec["bm25_questions"], rec["bm25_code"]
    if not has_questions:
        return [ids(p[:PLAIN_DEPTH])]
    lists = []
    if admitted(form, c, q, p, rec["attainable_questions"], rec["attainable_passages"]):
        lists.append(ids(q[:PLAIN_DEPTH]))
    lists.append(ids(p[:PLAIN_DEPTH]))
    if code_seat and admitted(form, c, code, p, rec["attainable_code"], rec["attainable_passages"]):
        lists.append(ids(code[:1]))
    return lists


def all_lists(rec, dense, form, c, code_seat, has_questions):
    lists = []
    if dense:
        lists.append(ids(rec["dense_passages"][:PLAIN_DEPTH]))
    lists.extend(lexical_lists(rec, form, c, code_seat, has_questions))
    return [l for l in lists if l]


def answer(rec, lists, nb, seats=SEATS):
    """`query::ask` from the lists on: exact seeds first, fused seats, one expanded neighbour."""
    exact = rec["exact"]["ids"]
    seeds = [(i, 1.0) for i in exact[:seats]]
    ranked = {}
    if not rec["exact"]["whole_question"]:
        for pos, (i, score) in enumerate(interleave(lists)):
            if len(seeds) < seats and i not in exact:
                seeds.append((i, score))
            ranked.setdefault(i, pos)
    seed_ids = [i for i, _ in seeds]
    cands = []
    for sid, sscore in seeds:
        for other in nb.get(sid, []):
            if other in seed_ids or other.startswith("file:") or other.startswith("deco:"):
                continue
            if any(cnd[2] == other for cnd in cands):
                continue
            cands.append((ranked.get(other), sscore * 0.5, other, sid))
    # Ranked before unranked, by rank, then by the seed's score falling, then by id.
    cands.sort(key=lambda cnd: (cnd[0] is None, cnd[0] if cnd[0] is not None else 0, -cnd[1], cnd[2]))
    return seed_ids, [cnd[2] for cnd in cands[:1]]


def found(rec, seeds, expanded, files):
    """`bench::found`: an id anchor counts anywhere, a path anchor only among the seeds."""
    reached = 0
    for anchor in anchors(rec["expect"]):
        if anchor in files:
            reached += anchor in seeds or anchor in expanded
        else:
            reached += any(files.get(s) == anchor for s in seeds)
    return reached


def replay(dump, store, form, c, code_seat):
    nb, files, has_questions = store
    out = []
    for rec in dump["queries"]:
        lists = all_lists(rec, dump["meta"]["dense"], form, c, code_seat, has_questions)
        seeds, expanded = answer(rec, lists, nb)
        out.append((rec, seeds, expanded))
    return out, files


def cmd_check(args):
    store = store_of(args.store)
    bad = 0
    for path in args.dumps:
        dump = load(path)
        rows, _ = replay(dump, store, args.form, args.c, args.code_seat)
        diffs = [(r["q"], s, e) for r, s, e in rows
                 if s != ids(r["ask"]["seeds"]) or e != [i for i, _, _ in r["ask"]["expanded"]]]
        bad += len(diffs)
        print(f"{Path(path).name}: {len(rows) - len(diffs)}/{len(rows)} replicated")
        for q, s, e in diffs[:5]:
            print(f"  differs: {q[:80]}\n    replay {s} + {e}")
    sys.exit(1 if bad else 0)


def cmd_crossover(args):
    """The constant: the split of the held-out questions by the form's statistic that puts the
    most of them on the side of the list holding their answer in its top five."""
    dump = load(args.heldout)
    if dump["meta"]["dense"] and not args.allow_dense:
        raise SystemExit("the constant is derived in the --no-dense arm; pass --allow-dense to read the other for information")
    rows = []
    for rec in dump["queries"]:
        p, q = rec["bm25_passages"][:PLAIN_DEPTH], rec["bm25_questions"][:PLAIN_DEPTH]
        if not q or q[0][1] <= 0:
            continue
        s = sratio(args.form, stat(args.form, q, rec["attainable_questions"]), stat(args.form, p, rec["attainable_passages"]))
        a = set(anchors(rec["expect"]))
        rows.append((s, bool(a & set(ids(q[:SEATS]))), bool(a & set(ids(p[:SEATS])))))
    finite = sorted({s for s, _, _ in rows if math.isfinite(s)})
    if not finite:
        raise SystemExit("every statistic is at an end: no crossover to derive")
    cuts = [finite[0] - 1] + [(x + y) / 2 for x, y in zip(finite, finite[1:])] + [finite[-1] + 1]

    def right(t):
        return sum((s >= t and qh and not ph) or (s < t and ph and not qh) for s, qh, ph in rows)

    best = max(cuts, key=lambda t: (right(t), -t))
    above = [(qh, ph) for s, qh, ph in rows if s >= best]
    below = [(qh, ph) for s, qh, ph in rows if s < best]
    pct = lambda xs, k: f"{100 * sum(x[k] for x in xs) / len(xs):.0f}%" if xs else "—"
    print(f"form={args.form} c={best:.3f}  ({len(rows)} questions with a questions list, {len(finite)} distinct finite values)")
    print(f"  above c: {len(above)} questions — questions list holds the answer in top five {pct(above, 0)}, passage list {pct(above, 1)}")
    print(f"  below c: {len(below)} questions — questions list {pct(below, 0)}, passage list {pct(below, 1)}")
    print(f"  questions on the side of the list that holds their answer: {right(best)}")


def score_suite(path, store, form, c, code_seat):
    dump = load(path)
    rows, files = replay(dump, store, form, c, code_seat)
    by_kind = {}
    for rec, seeds, expanded in rows:
        k = by_kind.setdefault(rec["kind"], [0, 0])
        k[1] += 1
        k[0] += found(rec, seeds, expanded, files) >= 1
    return by_kind


def cmd_score(args):
    store = store_of(args.store)
    for label, path in (("recorded", args.rec), ("developer", args.dev)):
        for p in path or []:
            k = score_suite(p, store, args.form, args.c, args.code_seat)
            counts = "  ".join(f"{kind} {h}/{n}" for kind, (h, n) in k.items())
            total = sum(h for h, _ in k.values())
            print(f"{label} {Path(p).name}: {counts}  total {total}")
    for p in args.ho or []:
        dump = load(p)
        rows, _ = replay(dump, store, args.form, args.c, args.code_seat)
        before, after = {}, {}
        for rec, seeds, _ in rows:
            key = (rec["q"], tuple(anchors(rec["expect"])))
            a = set(key[1])
            before[key] = bool(a & set(ids(rec["ask"]["seeds"][:SEATS])))
            after[key] = bool(a & set(seeds[:SEATS]))
        lost, gained, pv = mcnemar(before, after)
        n = len(before)
        print(f"held-out {Path(p).name}: recorded {sum(before.values())}/{n} → replay {sum(after.values())}/{n}  "
              f"{gained} gained, {lost} lost, exact McNemar p = {pv:.4f}")


def cmd_g13(args):
    """The G13 table under every form: where each `where`/`cross` file anchor sits in the code
    list and what each form's statistic says about seating that list."""
    dump = load(args.dump)
    _, files, _ = store_of(args.store)
    print("| kind | file anchor | code-list rank | " + " | ".join(FORMS) + " |")
    print("|---|---|---:|" + "---:|" * len(FORMS))
    for rec in dump["queries"]:
        if rec["kind"] not in ("where", "cross"):
            continue
        code, p = rec["bm25_code"], rec["bm25_passages"]
        for anchor in anchors(rec["expect"]):
            if anchor in files:
                continue
            rank = next((i + 1 for i, (cid, _) in enumerate(code) if files.get(cid) == anchor), None)
            if rank is None:
                continue
            cells = []
            for form in FORMS:
                s = sratio(form, stat(form, code, rec["attainable_code"]), stat(form, p, rec["attainable_passages"]))
                cells.append("∞" if s == math.inf else f"{s:.2f}")
            print(f"| {rec['kind']} | {anchor} | {rank} | " + " | ".join(cells) + " |")
```

```rust
/// How a lexical list earns its seats on the plain path: a statistic of the list's own, compared
/// with the passage list's, and the constant that comparison must clear.
///
/// `Ratio` is the gate that shipped up to 0.5.0: the two lists' best BM25 scores, admitted at
/// 0.85. On 400 held-out questions the passage list holds the answer below that ratio (30% in
/// its top five against 21%) and the questions list above it (24% against 12%); held-out never
/// binds the value (exact McNemar p = 0.34 to 0.79 from 0.80 to 0.95) and the 82 set its window
/// at (0.802, 0.866]. The trouble is the units. The two indices share the tokenizer, the formula
/// and the document count, but each normalises length against its own mean (30.6 tokens a
/// passage, 51.8 a question) and weights a term by its own vocabulary (10.8k against 21.8k), so a
/// population change in either moves the ratio while nothing about the query does — code
/// questions entering the questions index took `FR-WH-53` from 0.80 to 1.03 and cost the
/// `--no-dense` arm a keyword case (gaps G8 and G12).
///
/// The other three are scale-free: each measures a list's best against something of that list's
/// own index — what the query could attain there, the list's own fifth score, its own spread — so
/// the two compare in one unit. Which form ships, and its constant, is `ADMISSION`; the constant
/// is the crossover on the held-out set, derived by `bench/admission.py crossover` and never read
/// off a suite.
#[derive(Clone, Copy, Debug, PartialEq)]
pub enum Admission {
    /// best(list) ≥ c · best(passages)
    Ratio(f32),
    /// (best / attainable)(list) ≥ c · (best / attainable)(passages) — `LexicalIndex::attainable`
    Coverage(f32),
    /// (best / fifth)(list) ≥ c · (best / fifth)(passages); a list shorter than five seats is a peak of its own
    Peak(f32),
    /// z(list) ≥ c · z(passages), z the best as a z-score over the list as the plain path sees it
    Z(f32),
}

/// The admission that ships: the form and the constant the 0.5.0 gap work recorded on
/// 2026-09-05 (`docs/bench/2026-09-05-0.5.0-gaps-results.md`), the crossover on the held-out
/// set in the `--no-dense` arm.
const ADMISSION: Admission = Admission::Coverage(C);

/// Whether the code-questions list takes one seat on the plain path under `ADMISSION`. Off
/// unless stage B of the 0.5.0 gap plan measured it on: A4 read `where` 0/9 → 2/9 at six held-out
/// questions lost in each arm, none gained, p = 0.031, under the ratio; the measurement under
/// the scale-free form is recorded in `docs/bench/2026-09-05-0.5.0-gaps-results.md`.
const CODE_SEAT: bool = false;

/// One list's statistic under `form`, over the list as the plain path sees it.
fn statistic(form: Admission, list: &[(String, f32)], index: &LexicalIndex, query: &str) -> f32 {
    let Some(&(_, best)) = list.first() else { return 0.0 };
    match form {
        Admission::Ratio(_) => best,
        Admission::Coverage(_) => { let a = index.attainable(query); if a > 0.0 { best / a } else { 0.0 } }
        Admission::Peak(_) => match list.get(4) { Some(&(_, fifth)) if fifth > 0.0 => best / fifth, _ => f32::INFINITY },
        Admission::Z(_) => {
            if list.len() < 2 { return f32::INFINITY; }
            let n = list.len() as f32;
            let mean = list.iter().map(|(_, s)| s).sum::<f32>() / n;
            let sd = (list.iter().map(|(_, s)| (s - mean).powi(2)).sum::<f32>() / n).sqrt();
            if sd > 0.0 { (best - mean) / sd } else { f32::INFINITY }
        }
    }
}

impl Admission {
    fn constant(self) -> f32 {
        match self { Admission::Ratio(c) | Admission::Coverage(c) | Admission::Peak(c) | Admission::Z(c) => c }
    }

    /// Whether `list` is seated beside `passages`. A list with nothing to say never is, and a
    /// list that is the only one with something to say always is, whatever the form.
    fn admits(self, list: &[(String, f32)], index: &LexicalIndex, passages: &[(String, f32)], passages_index: &LexicalIndex, query: &str) -> bool {
        let Some(&(_, best)) = list.first() else { return false };
        if best <= 0.0 { return false; }
        let (own, theirs) = (statistic(self, list, index, query), statistic(self, passages, passages_index, query));
        // The ratio keeps the exact f32 product the window was measured on.
        if let Admission::Ratio(c) = self { return best >= c * theirs; }
        match (own.is_infinite(), theirs.is_infinite()) {
            (true, true) => 1.0 >= self.constant(),
            (true, false) => true,
            (false, true) => false,
            (false, false) => theirs <= 0.0 || own >= self.constant() * theirs,
        }
    }
}

/// `REPOGRAPH_QUESTIONS_GATE=<ratio>` and `REPOGRAPH_ADMISSION=<form>:<constant>` override
/// `ADMISSION` for a measurement and for nothing else. The gate variable is the older one and
/// wins: `0` reproduces the ungated fusion ADR-001 Amendment 6's before-column was read against.
/// A value that does not parse is ignored rather than read as zero.
fn admission() -> Admission {
    admission_from(std::env::var("REPOGRAPH_QUESTIONS_GATE").ok().as_deref(), std::env::var("REPOGRAPH_ADMISSION").ok().as_deref())
}

fn admission_from(gate: Option<&str>, form: Option<&str>) -> Admission {
    if let Some(c) = gate.and_then(|v| v.trim().parse::<f32>().ok()) { return Admission::Ratio(c); }
    let Some((name, c)) = form.and_then(|v| v.trim().split_once(':')) else { return ADMISSION };
    let Ok(c) = c.trim().parse::<f32>() else { return ADMISSION };
    match name.trim() {
        "ratio" => Admission::Ratio(c),
        "coverage" => Admission::Coverage(c),
        "peak" => Admission::Peak(c),
        "z" => Admission::Z(c),
        _ => ADMISSION,
    }
}

fn code_seat() -> bool {
    std::env::var_os("REPOGRAPH_CODE_SEAT").map_or(CODE_SEAT, |v| v == "1")
}
```

```rust
/// The lexical lists for one question, in fusion order. … (keep the existing paragraph of the
/// doc comment; its last sentence becomes:) The questions about code are a third list on the
/// reranked path, and on the plain path only when `CODE_SEAT` says a seat for them was measured
/// to cost the documents nothing.
fn lexical_lists_under(graph: &Graph, questions: &Questions, query: &str, depth: usize, reranked: bool, form: Admission, code_seat: bool) -> Vec<Vec<String>> {
    let only_ids = |scored: Vec<(String, f32)>| -> Vec<String> { scored.into_iter().map(|(id, _)| id).collect() };
    let passages_index = LexicalIndex::build(graph);
    let passages = passages_index.search(query, depth);
    if questions.entries.is_empty() { return vec![only_ids(passages)]; }
    let questions_index = LexicalIndex::build_questions(graph, questions);
    let generated = questions_index.search(query, depth);
    if reranked {
        let mut pool = vec![only_ids(passages), only_ids(generated)];
        // (keep the existing comment about the pool)
        let code = LexicalIndex::build_code_questions(graph, questions).search(query, depth);
        if !code.is_empty() { pool.push(only_ids(code)); }
        return pool;
    }
    let mut lists = Vec::with_capacity(3);
    if form.admits(&generated, &questions_index, &passages, &passages_index, query) { lists.push(only_ids(generated)); }
    lists.push(only_ids(passages));
    if code_seat {
        let code_index = LexicalIndex::build_code_questions(graph, questions);
        let code = code_index.search(query, depth);
        // One seat: `fuse::interleave` is a round-robin, so a one-element list takes at most the
        // slot its rank-one turn gives it and displaces no second document seed.
        if form.admits(&code, &code_index, &passages, &passages_index, query) { lists.push(only_ids(code).into_iter().take(1).collect()); }
    }
    lists
}
```

```rust
/// The BM25 indexes an answer fuses, built once from a graph and its questions and kept by
/// whoever answers more than one question over them: a resident `serve`, `bench` over its
/// cases, `dump` over a suite. Nothing here is written to disk — the indexes are term statistics

/// state that can go stale relative to the graph. What changed is who pays for the build: the
/// lexical arm through the socket spent almost all of 49 of its 54 ms rebuilding these per
/// question (`docs/bench/2026-09-06-perf-results.md`).

    pub passages: LexicalIndex,
    /// Absent on a store `enrich` never touched — see `build_questions`.
    pub questions: Option<LexicalIndex>,
    /// Absent unless some code node carries a question (`enrich --code`).
    pub code: Option<LexicalIndex>,
}

    pub fn build(graph: &Graph, questions: &Questions) -> Lexical {

        if questions.entries.is_empty() { return Lexical { passages, questions: None, code: None }; }
        let code = LexicalIndex::build_code_questions(graph, questions);
        Lexical { passages, questions: Some(LexicalIndex::build_questions(graph, questions)), code: if code.is_empty() { None } else { Some(code) } }
    }
}
```

```rust
/// Which prompt a batch is asked with. Documents and code never shared one because each kind
/// has its own prompt; decisions and invariants are a third: D1 measured the documents' prompt,
/// answered more literally by a stronger generator, losing four of nine "is this allowed"
/// answers on the developer suite (`ADR-005`, `ADR-031`, `INV-07`, `INV-10`) while every other
/// kind of question gained — gap G14.
#[derive(Clone, Copy, Debug, PartialEq)]
enum Prompt { Documents, Rules, Code }

struct Batch<'a> { nodes: Vec<(&'a Node, String)>, retry: bool, prompt: Prompt }

/// A document whose text is a decision or a constraint rather than a behaviour: an ADR records
/// what was chosen and what it rules out, an invariant what must never happen.
pub fn is_rule(n: &Node) -> bool { matches!(n.kind, NodeKind::Adr | NodeKind::Invariant) }

/// Stale nodes cut into batches, one prompt per batch.
fn batches<'a>(stale: Vec<(&'a Node, String)>, stale_code: Vec<(&'a Node, String)>, batch: usize) -> Vec<Batch<'a>> {
    let (rules, documents): (Vec<_>, Vec<_>) = stale.into_iter().partition(|(n, _)| is_rule(n));
    let cut = |nodes: Vec<(&'a Node, String)>, prompt: Prompt| -> Vec<Batch<'a>> {
        nodes.chunks(batch.max(1)).map(|c| Batch { nodes: c.to_vec(), retry: false, prompt }).collect()
    };
    let mut out = cut(documents, Prompt::Documents);
    out.extend(cut(rules, Prompt::Rules));
    out.extend(cut(stale_code, Prompt::Code));
    out
}
```

After `prompt`, the rules prompt — worded for the same corpus, and like the other two a rewording is a re-measure:

```rust
/// Worded for decisions and invariants: the questions a person about to do the forbidden thing
/// would ask, rather than the questions of someone looking for a behaviour. Measured on the
/// development corpus's ADRs and invariants (gap G14).
pub fn prompt_rules(nodes: &[&Node]) -> String {
    let mut p = String::from(
        "Below are entries from a product's documentation that record decisions and constraints: an id, \
         a title line and the start of the text. Each is an architecture decision (what was chosen, what \
         it rules out and why) or an invariant (what must never happen). For each entry write 12 short \
         questions (4-12 words) that a person who has never read this documentation could ask to find \
         exactly this entry when they need to know whether something is allowed: whether a thing may be \
         done, what forbids it, what was decided about it and why, and what would break if it were done \
         anyway. Write them as a developer, a product manager, a support employee and the business owner \
         would ask when about to do the thing the entry forbids or decides against — three each, every \
         one about a different rule or reason the entry states. Use everyday words, not the entry's own \
         terms: replace every specialised or product-specific word with what an ordinary person would \
         say, and vary the wording between questions so that no two share their key words. Then add one \
         line `id<TAB>synonyms: ...` with 5-10 everyday synonyms or paraphrases of the entry's key terms, \
         comma-separated. Every entry gets its lines, including one that has only a title. Write every \
         question and synonym in the language the entry itself is written in (a Russian entry gets \
         Russian questions), never translated. Output exactly one question per line, in the form \
         `id<TAB>text`, with no numbering and no commentary.\n\n");
    for n in nodes {
        p.push_str(&format!("### {}\n{}\n\n", n.id, passage(n)));
    }
    p
}
```
