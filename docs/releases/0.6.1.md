# zerograph 0.6.1

The release notes for the GitHub release page. The why behind each change is in the docs each line
links to.

## New

- **Verifiable binaries.** Every release archive and the binary inside it carry a build provenance
  attestation, and every release carries `SHA256SUMS`. `gh attestation verify <file> -R
  devmaxxx/zerograph` ties any copy, from the release page or from an npm install, to the workflow
  and commit that built it ([verifying a download](../install.md#verifying-a-download)).
- **`zerograph serve --detach`** starts a resident server in a process of its own, output in
  `.zerograph/serve.log`, and returns once it listens ([serve](../serve.md)).
- **`zerograph stop`** ends the server answering for a repository through the exit that removes its
  socket file, on Windows too ([serve](../serve.md)).

## Fixed

- **`npm i -g zerograph` under a running `serve` on Windows** no longer fails with a sharing error:
  the launcher runs a per-version copy of the binary from `%LOCALAPPDATA%\zerograph\bin`.
- **Windows first run:** the first model download prints the optional Defender exclusion command for
  the model cache.

## Docs

- npm is the recommended install route on every platform; on Windows it never meets SmartScreen.
- The Windows page is folded into [Windows notes](../install.md#windows-notes).
