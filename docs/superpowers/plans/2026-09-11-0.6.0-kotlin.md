# 0.6.0 Kotlin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read the six measurement gates 0.5.0 left, then ship a Kotlin extractor that names Kotlin symbols in `impact`, `trace` and `changes` on the pinned fixture's `mobile/` tree without moving a retrieval floor, then release 0.6.0 through a procedure that cannot lose its run to `[skip ci]`.

**Architecture:** Measurement first: the debt readings and a same-day blast baseline (B0) on the `v0.5.0` binary, through an instrument that splits `changes` scores by file extension. Then the extractor, in the order that keeps every step judgeable: K1 makes a globbed file with no grammar a file node and nothing else; K4 makes a nested member's container the nearest class; the Kotlin grammar and a hand walk under `src/code/kotlin/` write the node and edge kinds TypeScript already writes; K3 resolves imports through a qualified-name index built in `Resolver::new`'s existing walk; K7 puts `**/*.kt` in the default globs and K5 moves the grammar generation so a 0.5.0 store re-reads once. Last, every gate is read and the release is cut.

**Tech Stack:** Rust 2021 on toolchain 1.98.0, `tree-sitter =0.27.0`, one new crate `tree-sitter-kotlin-sg =0.4.1`. Python 3 stdlib for `bench/compare/`. Bash 3.2 and the `bench/probe/` kit, macOS only.

**Spec:** `docs/superpowers/specs/2026-09-11-0.6.0-kotlin-design.md`. Every task's acceptance criterion is a clause of its §5, copied into `docs/bench/2026-09-11-0.6.0-results.md` by Task 0. The debt tasks' criteria are the gates already committed in `docs/bench/2026-09-10-next-version-levers-results.md` §1, §2, §4, §6, §8 and §9.

- [ ] **Step 3: Implement `by_extension` and put it on the row**

Above `score_blast` in `run.py`:

```python
def by_extension(answer: str, want: dict) -> dict:
    """The four `changes` counts, split by the extension of the file the truth attributes them to.

    Every window in this corpus carries TypeScript and Kotlin together, and the totals cannot say
    which language a miss belongs to. A name the truth finds in files of two extensions counts in
    both slots, so the slots need not sum to the totals.
    """
    zero = lambda: {"want_files": 0, "found_files": 0, "want_symbols": 0, "found_symbols": 0}
    out: dict = {}
    for rel in want["code_files"]:
        slot = out.setdefault(Path(rel).suffix, zero())
        slot["want_files"] += 1
        slot["found_files"] += len(named(answer, [rel]))
    names: dict[str, set[str]] = {}
    for rel, syms in want["symbols"].items():
        names.setdefault(Path(rel).suffix, set()).update(syms)
    for ext, syms in names.items():
        slot = out.setdefault(ext, zero())
        slot["want_symbols"] = len(syms)
        slot["found_symbols"] = sum(1 for s in syms if spells(answer, s))
    return out
```

In the `changes` branch's `rows.append({...})`, add `"by_ext": by_extension(answer, want),` after `found_symbols`.

//! Which grammar reads a file, decided by its name alone.

use tree_sitter::{Language, Parser, Tree};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Lang {
    TypeScript,
    Tsx,
}

impl Lang {
    /// `None` for a name no grammar here reads. Such a file is indexed as a file and never parsed:
    /// every grammar returns a tree for any input, and a tree of the wrong language looks right.
    pub fn of(rel: &str) -> Option<Lang> {
        match std::path::Path::new(rel).extension().and_then(|e| e.to_str()) {
            Some("ts" | "mts" | "cts" | "js" | "mjs" | "cjs") => Some(Lang::TypeScript),
            Some("tsx" | "jsx") => Some(Lang::Tsx),
            _ => None,
        }
    }

    pub fn grammar(self) -> Language {
        match self {
            Lang::TypeScript => Language::new(tree_sitter_typescript::LANGUAGE_TYPESCRIPT),
            Lang::Tsx => Language::new(tree_sitter_typescript::LANGUAGE_TSX),
        }
    }

    pub fn parse(self, src: &[u8]) -> Option<Tree> {
        let mut parser = Parser::new();
        parser.set_language(&self.grammar()).ok()?;
        parser.parse(src, None)
    }
}

/// One stderr line naming what was indexed without being read, so a glob that reaches past the
/// grammars says so instead of producing a graph that is silently thinner than the tree.
pub fn files_only_note<'a>(rels: impl Iterator<Item = &'a str>) -> Option<String> {
    let mut by_ext = std::collections::BTreeMap::<String, usize>::new();
    for rel in rels.filter(|r| Lang::of(r).is_none()) {
        let ext = std::path::Path::new(rel).extension().and_then(|e| e.to_str())
            .map(|e| format!(".{e}")).unwrap_or_else(|| "(no extension)".to_string());
        *by_ext.entry(ext).or_default() += 1;
    }
    if by_ext.is_empty() {
        return None;
    }
    let mut parts: Vec<(String, usize)> = by_ext.into_iter().collect();
    parts.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(&b.0)));
    let list = parts.iter().map(|(e, n)| format!("{n} {e}")).collect::<Vec<_>>().join(", ");
    Some(format!("code: no grammar reads {list} — indexed as files only"))
}

use std::collections::{BTreeMap, BTreeSet};

use tree_sitter::Node;

use crate::model::{EdgeKind, Extraction, NodeKind};

#[derive(Default)]
pub struct Declared {
    /// Top-level names this file declares.
    pub top: BTreeSet<String>,
    /// Per class or object id, each property's declared type name, constructor `val`s included.
    pub types: BTreeMap<String, BTreeMap<String, String>>,
    /// (class id, supertype name) pairs, resolved in this file where they can be.
    pub supers: Vec<(String, String)>,
}

fn text<'a>(n: Node, src: &'a [u8]) -> &'a str {
    n.utf8_text(src).unwrap_or("")
}

fn named<'t>(n: Node<'t>) -> Vec<Node<'t>> {
    let mut c = n.walk();
    n.named_children(&mut c).collect()
}

fn child<'t>(n: Node<'t>, kind: &str) -> Option<Node<'t>> {
    named(n).into_iter().find(|c| c.kind() == kind)
}

fn span(n: Node) -> (u32, u32) {
    (n.start_position().row as u32 + 1, n.end_position().row as u32 + 1)
}

/// Kotlin is public by default; `internal` crosses files, so only these two keep a name in its file.
fn hidden(n: Node, src: &[u8]) -> bool {
    child(n, "modifiers").is_some_and(|m| named(m).into_iter()
        .any(|c| c.kind() == "visibility_modifier" && matches!(text(c, src), "private" | "protected")))
}

fn type_name(n: Node, src: &[u8]) -> Option<String> {
    let user = if n.kind() == "user_type" { n } else { child(n, "user_type")? };
    child(user, "type_identifier").map(|t| text(t, src).to_string())
}

pub fn scan(root: Node, rel: &str, src: &[u8], ex: &mut Extraction) -> Declared {
    let file_id = format!("file:{rel}");
    ex.node(NodeKind::File, &file_id, rel, "", rel, 1);
    let mut d = Declared::default();
    for n in named(root) {
        declare(n, rel, src, &file_id, None, ex, &mut d);
    }
    let local: Vec<(String, String)> = std::mem::take(&mut d.supers);
    for (from, name) in local {
        if d.top.contains(&name) {
            ex.edge(&from, &format!("sym:{rel}::{name}"), EdgeKind::Extends, "", rel);
        } else {
            d.supers.push((from, name));
        }
    }
    d
}

fn declare(n: Node, rel: &str, src: &[u8], parent: &str, owner: Option<&str>, ex: &mut Extraction, d: &mut Declared) {
    let name = match n.kind() {
        "class_declaration" | "object_declaration" | "type_alias" => child(n, "type_identifier").map(|c| text(c, src).to_string()),
        "function_declaration" => child(n, "simple_identifier").map(|c| text(c, src).to_string()),
        "property_declaration" => child(n, "variable_declaration")
            .and_then(|v| child(v, "simple_identifier")).map(|c| text(c, src).to_string()),
        // A caller writes `Outer.make()`, so a companion's members are the class's own.
        "companion_object" => {
            if let (Some(body), Some(_)) = (child(n, "class_body"), owner) {
                for m in named(body) {
                    declare(m, rel, src, parent, owner, ex, d);
                }
            }
            return;
        }
        _ => None,
    };
    let Some(name) = name else { return };
    let qualified = owner.map_or_else(|| name.clone(), |o| format!("{o}.{name}"));
    let id = format!("sym:{rel}::{qualified}");
    let context = if hidden(n, src) { "" } else { "export" };
    ex.node_span(NodeKind::Symbol, &id, &qualified, "", rel, span(n));
    ex.edge(parent, &id, EdgeKind::Declares, context, rel);
    if owner.is_none() {
        d.top.insert(name.clone());
    }
    if let (Some(o), "property_declaration") = (owner, n.kind()) {
        if let Some(t) = named(n).into_iter().find_map(|c| type_name(c, src)) {
            let class_id = format!("sym:{rel}::{o}");
            d.types.entry(class_id).or_default().insert(name.clone(), t);
        }
    }
    if !matches!(n.kind(), "class_declaration" | "object_declaration") {
        return;
    }
    for spec in named(n).into_iter().filter(|c| c.kind() == "delegation_specifier") {
        let target = child(spec, "constructor_invocation").unwrap_or(spec);
        if let Some(t) = type_name(target, src) {
            d.supers.push((id.clone(), t));
        }
    }
    if let Some(ctor) = child(n, "primary_constructor") {
        for p in named(ctor).into_iter().filter(|p| p.kind() == "class_parameter" && child(*p, "binding_pattern_kind").is_some()) {
            let (Some(pname), Some(ptype)) = (child(p, "simple_identifier"), type_name(p, src)) else { continue };
            let pname = text(pname, src).to_string();
            let pid = format!("{id}.{pname}");
            let pcontext = if hidden(p, src) { "" } else { "export" };
            ex.node_span(NodeKind::Symbol, &pid, &format!("{qualified}.{pname}"), "", rel, span(p));
            ex.edge(&id, &pid, EdgeKind::Declares, pcontext, rel);
            d.types.entry(id.clone()).or_default().insert(pname, ptype);
        }
    }
    if let Some(body) = child(n, "class_body").or_else(|| child(n, "enum_class_body")) {
        for m in named(body) {
            declare(m, rel, src, &id, Some(&qualified), ex, d);
        }
    }
}

fn walk(n: Node, at: At, resolver: &Resolver, rel: &str, src: &[u8], d: &Declared, ex: &mut Extraction) {
    let mut at = at;
    match n.kind() {
        "class_declaration" | "object_declaration" => {
            if let Some(name) = name_of(n, src) {
                at.class = Some(at.class.map_or(name.clone(), |c| format!("{c}.{name}")));
                at.function = None;
            }
        }
        "function_declaration" => {
            if let Some(name) = name_of(n, src) {
                let owner = at.class.as_ref().map_or(name.clone(), |c| format!("{c}.{name}"));
                at.function = Some(format!("sym:{rel}::{owner}"));
            }
        }
        "call_expression" => {
            if let (Some(from), Some(callee)) = (at.function.as_deref(), n.named_child(0)) {
                for to in targets(callee, &at, resolver, rel, src, d) {
                    if to != from {
                        ex.edge(from, &to, EdgeKind::Calls, "", rel);
                    }
                }
            }
        }
        _ => {}
    }
    for c in named(n) {
        walk(c, at.clone(), resolver, rel, src, d, ex);
    }
}

/// The ids a callee reaches: `f()`, `x.m()` and `this.x.m()` on a typed property, `Obj.m()`.
fn targets(callee: Node, at: &At, resolver: &Resolver, rel: &str, src: &[u8], d: &Declared) -> Vec<String> {
    match callee.kind() {
        "simple_identifier" => {
            let name = text(callee, src);
            // Inside a class, an unqualified name is its own member before it is anything else.
            if let Some(class) = &at.class {
                let member = format!("sym:{rel}::{class}.{name}");
                if d.members.contains(&member) {
                    return vec![member];
                }
            }
            if d.top.contains(name) {
                return vec![format!("sym:{rel}::{name}")];
            }
            elsewhere(resolver, rel, name, None)
        }
        "navigation_expression" => {
            let parts = named(callee);
            let (Some(receiver), Some(suffix)) = (parts.first().copied(), parts.last().copied()) else { return Vec::new() };
            let Some(method) = child(suffix, "simple_identifier").map(|m| text(m, src).to_string()) else { return Vec::new() };
            let receiver = match receiver.kind() {
                // `this.x` is the property `x`.
                "navigation_expression" if child(receiver, "this_expression").is_some() => {
                    named(receiver).last().and_then(|s| child(*s, "simple_identifier")).map(|s| text(s, src).to_string())
                }
                "simple_identifier" => Some(text(receiver, src).to_string()),
                _ => None,
            };
            let Some(receiver) = receiver else { return Vec::new() };
            let typed = at.class.as_ref().and_then(|c| d.types.get(&format!("sym:{rel}::{c}"))).and_then(|t| t.get(&receiver));
            let type_name = typed.cloned().unwrap_or(receiver);
            if d.top.contains(&type_name) {
                return vec![format!("sym:{rel}::{type_name}.{method}")];
            }
            elsewhere(resolver, rel, &type_name, Some(&method))
        }
        _ => Vec::new(),
    }

use std::collections::{BTreeMap, BTreeSet};

use crate::code::lang::Lang;
use crate::model::Extraction;

#[derive(Debug, Default, Clone, PartialEq, Eq)]
pub struct Header {
    pub package: String,
    pub names: BTreeSet<String>,
    /// (the name a file uses, the qualified name it stands for); `("*", "a.b")` for `import a.b.*`.
    pub imports: Vec<(String, String)>,
}

fn dotted(n: tree_sitter::Node, src: &[u8]) -> String {
    n.utf8_text(src).unwrap_or("").split_whitespace().collect()
}

pub fn header_of(src: &[u8]) -> Header {
    let Some(tree) = Lang::Kotlin.parse(src) else { return Header::default() };
    let root = tree.root_node();
    let mut h = Header::default();
    let mut c = root.walk();
    for n in root.named_children(&mut c) {
        match n.kind() {
            "package_header" => {
                if let Some(id) = n.named_child(0) { h.package = dotted(id, src); }
            }
            "import_list" | "import_header" => {
                let mut ic = n.walk();
                let headers: Vec<_> = if n.kind() == "import_list" { n.named_children(&mut ic).collect() } else { vec![n] };
                for ih in headers {
                    let Some(id) = ih.named_child(0) else { continue };
                    let fqn = dotted(id, src);
                    let mut hc = ih.walk();
                    let kids: Vec<_> = ih.named_children(&mut hc).collect();
                    if kids.iter().any(|k| k.kind() == "wildcard_import") {
                        h.imports.push(("*".into(), fqn));
                    } else if let Some(alias) = kids.iter().find(|k| k.kind() == "import_alias") {
                        h.imports.push((dotted(*alias, src).trim_start_matches("as").to_string(), fqn));
                    } else {
                        let last = fqn.rsplit('.').next().unwrap_or(&fqn).to_string();
                        h.imports.push((last, fqn));
                    }
                }
            }
            _ => {}
        }
    }
    let mut scratch = Extraction::default();
    h.names = super::declarations::scan(root, "", src, &mut scratch).top;
    h
}

#[derive(Debug, Default)]
pub struct Index {
    by_fqn: BTreeMap<String, BTreeSet<String>>,
    by_file: BTreeMap<String, Header>,
}

fn fqn(package: &str, name: &str) -> String {
    if package.is_empty() { name.to_string() } else { format!("{package}.{name}") }
}

impl Index {
    pub fn insert(&mut self, rel: &str, header: Header) {
        self.remove(rel);
        for name in &header.names {
            self.by_fqn.entry(fqn(&header.package, name)).or_default().insert(rel.to_string());
        }
        self.by_file.insert(rel.to_string(), header);
    }

    pub fn remove(&mut self, rel: &str) {
        let Some(old) = self.by_file.remove(rel) else { return };
        for name in &old.names {
            let key = fqn(&old.package, name);
            if let Some(files) = self.by_fqn.get_mut(&key) {
                files.remove(rel);
                if files.is_empty() { self.by_fqn.remove(&key); }
            }
        }
    }

    pub fn header(&self, rel: &str) -> Option<&Header> {
        self.by_file.get(rel)
    }

    pub fn declaring(&self, fqn: &str) -> Vec<String> {
        self.by_fqn.get(fqn).map(|f| f.iter().cloned().collect()).unwrap_or_default()
    }

    pub fn resolve(&self, from: &str, name: &str) -> Vec<String> {
        let Some(h) = self.by_file.get(from) else { return Vec::new() };
        if let Some((_, q)) = h.imports.iter().find(|(local, _)| local == name) {
            return self.declaring(q);
        }
        let own = self.declaring(&fqn(&h.package, name));
        if !own.is_empty() {
            return own;
        }
        h.imports.iter().filter(|(local, _)| local == "*")
            .map(|(_, pkg)| self.declaring(&fqn(pkg, name)))
            .find(|f| !f.is_empty()).unwrap_or_default()
    }
}
