> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close out the 2026-09-05 measurement campaign on `feat/dev-cases`: land the last two retrieval levers that have a pre-registered rule and a store copy waiting (one seat for the code-questions list; the embedding model as a property of the store), read the last token lever (D1), write every number into the docs and the history, refresh the fixture store if a lever ships, trim the artifact, open the PR.

**Architecture:** repograph is a Rust CLI (`src/`) over a `.repograph/` store (graph, BM25 built at query time, dense vectors on disk, generated questions). Retrieval fuses ranked lists round-robin into five seeds (`src/query.rs::ask`, `src/index/fuse.rs::interleave`); a list joins the fusion only when its best BM25 score clears a gate against the passage list (`QUESTIONS_GATE = 0.85`). Every lever is measured on a **copy** of the store in the session scratchpad, judged by a rule written before the numbers are read, and recorded in the SDD ledger, the results doc and `bench/history/runs.jsonl`.

**Tech Stack:** Rust 2021 (`cargo test --release`, `cargo clippy --release --all-targets`), Python 3.14 stdlib only (`bench/heldout.py`, `bench/history/track.py`), bash 3.2, the `claude` CLI 2.1.261 as the question generator.

**Spec:** `docs/bench/2026-09-05-dev-cases-results.md` (the weak spots A/B/C and the pre-registered rules), with the rulings in the previous plan's ledger `.superpowers/sdd/dev-cases/progress.md` (read-only history for this plan; do not append to it).

```python
"""Per-case flips between two bench transcripts: python3 flips.py before.txt after.txt"""
import re, sys
pat = re.compile(r'^(\w+)\s+(\S+)\s+(HIT|miss)\s+(\d+)/(\d+)\s+(\d+) tok')
def load(f):
    out = {}
    for line in open(f, encoding="utf-8", errors="replace"):
        m = pat.match(line)
        if m: out[(m[1], m[2])] = (m[3], int(m[4]), int(m[5]), int(m[6]))
    return out
b, a = load(sys.argv[1]), load(sys.argv[2])
for k in b:
    if k in a and (b[k][0] != a[k][0] or b[k][1] != a[k][1]):
        print(f"  {k[0]:10} {k[1][:60]:60} {b[k][0]} {b[k][1]}/{b[k][2]} -> {a[k][0]} {a[k][1]}/{a[k][2]}")
```

```rust
    pub fn recorded_model(store: &Store) -> Result<Option<String>> {
        #[derive(serde::Deserialize)]
        struct Written { #[serde(default)] model: String }
        let Some(meta) = store.read_bytes("vectors.json")? else { return Ok(None) };
        let w: Written = serde_json::from_slice(&meta).context("vectors.json")?;
        Ok(Some(w.model).filter(|m| !m.is_empty()))
    }

    /// Claims the index for `model` before a sync. Rows another model wrote cannot be appended
    /// to or compared against — a width change would be caught, an equal width would not — so
    /// they go and the file is rewritten from the new rows alone. An unnamed store is the small
    /// model's, the only one that wrote stores before the field existed.
    pub fn written_by(&mut self, model: &str) {
        let held = if self.model.is_empty() { crate::index::embed::DEFAULT_MODEL } else { self.model.as_str() };
        if !self.ids.is_empty() && held != model {
            self.ids.clear(); self.hashes.clear(); self.kinds.clear(); self.vectors.clear();
            self.free.clear(); self.live.clear();
            self.persisted = 0; self.dim = 0;
        }
        self.model = model.to_string();
    }
```
