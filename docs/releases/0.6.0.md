# zerograph 0.6.0

The release notes for the GitHub release page. The why behind each change is in the docs each line
links to.

## Read this before upgrading

- **repograph is now zerograph.** The package is `zerograph`, on the public npm registry with no
  `.npmrc` to write, the binary `zerograph`, the store `.zerograph/`, the project file
  `zerograph.toml`, the variables `ZEROGRAPH_*`. Everything under the old names is read and moved
  on first write. There is no `repograph` command any more, and `@devmaxxx/repograph` gets no
  further release: remove it and add `zerograph`. Stop any `repograph serve` or `watch` before the
  first zerograph run, then re-run `zerograph install-agent`. The steps and their order are in
  [Coming from repograph](../install.md#coming-from-repograph).
- **`enrich` is removed.** Under the new default embedder it bought one paraphrase case of 30 for
  about $2.5 a corpus. The `enrich_*` keys still parse and say they are no longer read; a store's
  `questions.json` is left in place and ignored ([rerank](../rerank.md)).
- **A 0.6.0 store is not readable by 0.5.x** once it holds text nodes: 0.5.x stops on
  `unknown variant Text` ([configuration](../configuration.md)).
- **The default embedder is `onnx-community/embeddinggemma-300m-ONNX`**, under Gemma's terms
  ([ADR-003](../adr/ADR-003-gemma-is-the-default.md)). A store keeps answering with the model that
  wrote it; `zerograph model` switches it and re-embeds ([embeddings](../embeddings.md)).
- **`ask --rerank` runs `claude -p --model haiku`** on each candidate's matching sentence, and needs
  the `claude` CLI signed in. Rerank is still opt-in and is the only stage that spends tokens
  ([ADR-004](../adr/ADR-004-haiku-reranks-by-default.md)).
- **Windows is built and tested in CI only.** Nobody has run 0.6.0 on a real Windows machine yet
  ([Windows](../install.md#windows-notes)).

## New

- Many more languages, all read through one generic tree-sitter engine: C#, Kotlin, Java,
  PostgreSQL, GraphQL, Rust, Python, Shell, Bicep, Terraform/HCL, Dart, Swift, Vue, and more. The
  table of what each one reads is in [Languages](../languages.md). Razor is read but stays out of
  the default globs.
- Files no glob claims can be indexed as text nodes with `text_globs`. This is off by default.
- Interface members and `implements`, so a call through a port reaches its adapter. Value uses in
  DI objects, arrays, decorator arguments and getter reads count as edges. Methods of an exported
  object literal are symbols.
- `explain` neighbour rows name the file and line of their edge.
- Readers answer within `reader_budget` seconds and leave a large refresh to a detached `update`
  ([keeping fresh](../keeping-fresh.md)).
- `resources = "balanced"` holds a build to 30% of the logical cores.

## Hardening

- A cloned repository cannot write outside itself, choose the embedder, or point the reranker at
  its own model or command. Store files that are links, devices or oversized are refused on every
  read.
- Catalogued embedders are fetched at the hub commit they were measured on, not at the model's
  moving `main`.
- A rerank command still running after 180 seconds is stopped (with everything it started, except on Windows), and the
  answer falls back to the fused order.
- MCP `ask` runs at most `mcp_reranks` paid reranks per server process (25 by default, set in the
  machine config only).
- The release workflow refuses a tag whose version is not `Cargo.toml`'s.
