# zerograph 0.6.3

The release notes for the GitHub release page. The why behind each change is in the docs each line
links to.

## New

- **`install-agent` for more agents.** `--cursor`, `--copilot` (VS Code), `--gemini` (Gemini CLI)
  and `--opencode` write the agent's project MCP file with a `zerograph` server and the stanza into
  the instructions file it always reads. Existing files are merged, other servers and settings
  kept; any subset combines with `--claude` and `--codex` ([other agents](../mcp.md#other-agents)).
